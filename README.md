# 전화 메모

회사에서 통화 내용을 빠르게 기록하고 검색하는 브라우저 기반 메모 앱입니다. 서버나 외부 라이브러리 없이 동작하며 메모는 현재 브라우저의 `localStorage`에 저장됩니다.

## 실행

`index.html`을 최신 Chrome 또는 Edge에서 엽니다. 로컬 파일 환경에서도 ID 생성이 동작하지만, 회사에서 배포할 때는 HTTPS 정적 호스팅을 권장합니다.

## 사용

- **새 통화**: 빈 메모를 만듭니다.
- **검색**: 키워드 또는 전화번호 일부를 입력합니다.
- **자동 저장**: 입력이 멈춘 뒤 약 0.4초 후 저장합니다.
- **내보내기**: 모든 메모를 날짜가 포함된 JSON 파일로 내려받습니다.
- **가져오기**: 이 앱에서 내보낸 JSON 파일을 선택해 현재 메모 전체를 교체합니다.
- **삭제**: 상단 삭제 버튼이나 목록의 우클릭 메뉴를 사용합니다. 마지막 메모 하나는 삭제할 수 없습니다.

가져오기는 현재 데이터를 교체하므로 먼저 내보내기로 백업하는 것을 권장합니다.

## 데이터와 보안

- 메모는 브라우저의 `callNotes` 키에 평문으로 저장됩니다.
- 전화번호와 통화 내용에 개인정보가 포함될 수 있으므로 공용 PC 사용을 피하고 회사의 개인정보 보관 정책을 따르세요.
- 브라우저 데이터 삭제, 프로필 초기화 또는 PC 교체 전에 반드시 내보내기로 백업하세요.
- 손상된 저장 데이터를 발견하면 원본을 `callNotes_recovery_...` 키에 먼저 보관한 뒤 유효한 메모만 복구합니다.
- 저장 실패 메시지가 표시되면 페이지를 닫기 전에 내보내기로 현재 메모를 보관하세요.

## 테스트

Node.js 18 이상에서 다음 명령을 실행합니다.

```sh
npm test
```

테스트는 저장/로드, 유효성 검사, 손상 데이터 감지, 가져오기 형식, ID 생성을 확인합니다.
